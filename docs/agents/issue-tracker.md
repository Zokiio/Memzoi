# Issue tracker: GitHub

Issues and PRDs for this repository live in GitHub Issues under `Zokiio/Memzoi`.

## Conventions

- Prefer the connected GitHub app for reading, creating, updating, labeling, and commenting on issues.
- Use `gh` only when the connector does not cover the operation or exact tracker metadata is otherwise unavailable.
- Infer the repository from the `origin` remote when operating from a local checkout.
- Create implementation issues in dependency order so blockers can reference real issue numbers.
- Use the parent issue, acceptance criteria, and `Blocked by` section defined by the issue-oriented skill.

## Skill terminology

When a skill says "publish to the issue tracker," create a GitHub issue in `Zokiio/Memzoi`.

When a skill says "fetch the relevant ticket," fetch its complete issue body, labels, milestone, and comments from GitHub.
