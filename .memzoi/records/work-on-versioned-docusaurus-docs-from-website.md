# Work on versioned Docusaurus docs from website

The Docusaurus application is rooted at website/. Run documentation commands there or with that explicit working directory. Unreleased docs live under website/docs and are served as Next; released snapshots are created with the website docs:version command and the latest released snapshot is served at the site root. Generated website build, .docusaurus, and dependency directories remain disposable and ignored.
