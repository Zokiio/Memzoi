# Automatic private maintenance has separate opt-in authority

Automatic private maintenance is a separate opt-in, versioned local maintenance policy over selected runtime records, regardless of origin integration. Event-local exact dedupe, provenance renewal, and direct correction reconciliation are part of applying an authorized inference event; corpus-wide maintenance requires its own grant. Ambiguous truth selection never runs automatically, destructive redaction or deletion requires approval, and repository materialization remains a separate explicit CLI decision.
