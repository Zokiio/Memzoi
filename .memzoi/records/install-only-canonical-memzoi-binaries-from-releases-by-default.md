# Install only canonical Memzoi binaries from releases by default

Normal installation should download verified GitHub Release assets and install only the canonical memzoi and memzoi-mcp binaries. Cargo is reserved for explicit source or branch installs. Do not restore the old agent-memory compatibility aliases before v1.0.
