# Memzoi is primary local-first memory with selective Git truth

Memzoi should become the user's primary local-first memory substrate across agents and harnesses. Personal, local, and session memory remain private runtime state; only the curated subset that is durable shared project knowledge becomes Git-native, human-readable, and reviewable repository truth. Optional provider, remote, and cloud integrations may extend access later without weakening local ownership, privacy, provenance, or Git review.
