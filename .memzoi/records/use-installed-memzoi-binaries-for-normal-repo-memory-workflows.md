# Use installed Memzoi binaries for normal repo memory workflows

For normal memory workflows in this repo, install Memzoi with make install and run memzoi/memzoi-mcp from the user Cargo bin directory on PATH. Use cargo run or ./target/debug only for development-mode testing while editing the binaries.
